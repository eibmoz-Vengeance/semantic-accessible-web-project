Semantic Accessible Web Project

About This Project

Exploring a web that is easier to understand, navigate, and use.

The idea we're exploring

The Semantic Accessible Web Project is an early, small-scale exploration of how thoughtful structure, accessibility, and separation of concerns can make websites and web applications easier to use and easier to develop.

Our long-term interest is an ease-of-use library: reusable tools and patterns that could help developers build experiences that make sense to people, work well with assistive technologies, and expose clearer, more meaningful structure for AI-powered and other machine-assisted interactions.

This is an area for learning and experimentation, not a claim that one library or technique can solve every accessibility or AI interaction challenge. The aim is to explore practical ideas, test them, learn from the results, and improve them over time.

Why start with a number-guessing game?

The interactive number-guessing game is our first test case. It gives us a manageable place to explore feedback, keyboard interaction, screen-reader announcements, clear controls, and the separation of game logic from the way information is presented.

The game is a simple demonstration for a school assignment that helped spark this interest. It includes some additional layers to illustrate the idea; it is not the finished library, and the reusable library code is not currently included in this game project.

Any future library implementation will be developed and tested separately. If that work becomes dependable and useful, it may eventually replace the simple demonstration with a more reusable approach.

What we hope to learn

  • How semantic HTML and appropriate accessibility features can make interfaces easier to understand.
  • How to provide useful feedback without unnecessary or repetitive announcements.
  • How to keep interface behavior, application logic, and presentation concerns clearly separated.
  • How reusable patterns might support websites, web applications, and interactive experiences such as games.
  • How clearer structure and predictable interactions might also help AI systems work with web experiences more reliably.

A hobby project, built gradually

Flat Tire Studio intends to explore this idea gradually as a hobby project. For now, we are experimenting with the concept and learning from a small example rather than presenting a finished product or promising a release date.

We believe better assistive technology and more usable digital experiences are worth exploring together. We are not asking others to credit us for the general idea of accessibility or ease of use. If the project develops into something practical, we may explore collaboration and an open-source release with others who share these goals.

For now, this page records the direction we are exploring—not a finished specification, a released library, or a request for contributions.

The web should not require users to understand the interface before the interface understands the user.
